Primer Proyecto en Flutter

Estructura de código base para verificar que todo tu entorno compile correctamente.

Código Base: main.dart

Reemplaza todo el contenido de tu archivo lib/main.dart en Visual Studio Code con el siguiente bloque de código:

import 'package:flutter/material.dart';

void main() {
  runApp(const MiApp());
}

class MiApp extends StatelessWidget {
  const MiApp({super.html});

  @override
  Widget build(BuildContext context) {
    return const MaterialApp(
      debugShowCheckedModeBanner: false,
      home: Scaffold(
        body: Center(
          child: Text(
            '¡Hola Mundo equipo D 180!',
            style: TextStyle(fontSize: 24, fontWeight: FontWeight.bold),
          ),
        ),
      ),
    );
  }
}

¿Cómo ejecutar el ejemplo?

  1. Asegúrate de tener un emulador encendido (revisa la sección de Emuladores si no sabes cómo).
  2. Presiona la tecla F5 en tu teclado o ve a la pestaña superior Run > Start Debugging.
  3. El código se compilará y verás el mensaje centrado en la pantalla de tu dispositivo virtual.
