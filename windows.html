Instalación en Windows

Configuración del entorno utilizando el IDE Visual Studio Code.

1. Requisitos previos

  • Sistema Operativo Windows 10 u 11
  • Tener instalado Visual Studio Code
  • Conexión a Internet

2. Configuración en Visual Studio Code

  1. Abre Visual Studio Code en tu computadora.
  2. Dirígete al icono de Extensiones en la barra lateral izquierda (o presiona Ctrl + Mayús + X).
  3. En el buscador, escribe el nombre del paquete o lenguaje que necesitas instalar.
  4. Haz clic en el botón azul de Instalar.

3. Ejecución desde la Terminal Integrada

Puedes usar la consola interna de VS Code para finalizar la configuración:

Abre la terminal con Ctrl + ñ (o Ver > Terminal) y ejecuta:

./instalador-windows.exe /silent
