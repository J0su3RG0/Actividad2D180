Guía de Instalación: [Flutter Equipo D180]

Sigue estos pasos sencillos para completar la instalación en tu equipo.

Otras plataformas: Ver guía para Linux 🐧 Ver guía para Windows

1. Requisitos previos

  • Sistema operativo compatible (Windows, Mac o Linux)
  • Espacio libre en disco: 500 MB
  • Permisos de administrador

2. Pasos para instalar

  1. Descarga el archivo de instalación desde el sitio oficial.
  2. Ejecuta el archivo descargado con doble clic.
  3. Acepta los términos y condiciones de uso.
  4. Selecciona la carpeta de destino y haz clic en Instalar.

3. Instalación por consola (Opcional)

Si prefieres usar la terminal, ejecuta el siguiente comando:

npm install nombre-del-paquete
