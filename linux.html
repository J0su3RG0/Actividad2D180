Guía de Instalación: Linux

Instrucciones detalladas para distribuciones basadas en Ubuntu, Debian, Fedora y Arch.

← Volver al inicio

1. Requisitos previos

  • Acceso a la terminal con permisos de sudo
  • Conexión activa a Internet
  • Administrador de paquetes (apt, dnf o pacman) instalado

2. Instalación por comandos

Abre tu terminal (Ctrl + Alt + T) y ejecuta los comandos correspondientes a tu distribución:

Ubuntu / Debian

sudo apt update && sudo apt install nombre-del-paquete

Fedora / RHEL

sudo dnf install nombre-del-paquete

Arch Linux

sudo pacman -S nombre-del-paquete

3. Verificar la instalación

Una vez terminado el proceso, comprueba que el programa funciona correctamente con el siguiente comando:

nombre-del-paquete --version
