Configuración de Emuladores

Prepara tus dispositivos virtuales para probar tus aplicaciones móviles.

1. Android Emulator (Windows / Linux / macOS)

Para probar aplicaciones Android de manera local, necesitas configurar un dispositivo virtual (AVD) a través de Android Studio.

Requisito de Hardware: Asegúrate de tener activada la Virtualización (VT-x / AMD-V) en la BIOS de tu computadora; de lo contrario, el emulador irá extremadamente lento o no abrirá.

Pasos de configuración:

  1. Descarga e instala Android Studio.
  2. Abre el programa y dirígete a More Actions > Virtual Device Manager.
  3. Haz clic en Create Device y selecciona un modelo de teléfono (por ejemplo, Pixel 7).
  4. Descarga la imagen del sistema recomendada (ej. Android 13 / API 33) y haz clic en Next.
  5. Asigna un nombre a tu emulador y presiona Finish. ¡Ya puedes iniciarlo con el botón de "Play"!

2. Simulador de iOS (Exclusivo macOS)

Debido a las restricciones del ecosistema de Apple, la emulación y desarrollo de iOS solo se puede realizar en computadoras Mac.

Nota: El simulador de iOS consume significativamente menos recursos de memoria RAM que el emulador de Android.

Pasos de configuración:

  1. Abre la App Store en tu Mac e instala Xcode.
  2. Una vez instalado, abre la Terminal de macOS y ejecuta el siguiente comando para instalar las herramientas de línea de comandos:
    3. xcode-select --install
  3. Abre Xcode, ve a las preferencias del programa (Settings > Platforms) y asegúrate de tener descargado el paquete de iOS más reciente.
  4. Para abrir el simulador directamente desde la consola, ejecuta:
    5. open -a Simulator

3. Lanzar emuladores desde VS Code

No necesitas abrir Android Studio o Xcode cada vez que programes. Desde Visual Studio Code puedes controlarlos:

  1. En la barra inferior derecha de VS Code, busca un texto que dice No Device o muestra un dispositivo actual.
  2. Haz clic sobre él; se desplegará una lista con tus emuladores configurados en la parte superior central.
  3. Selecciona el emulador deseado y se encenderá automáticamente en tu pantalla.
