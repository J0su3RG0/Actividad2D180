Solución de Problemas

Soluciones rápidas a los errores más comunes durante la configuración de Flutter.

1. Flutter doctor encuentra problemas (X)

Si al ejecutar el comando aparecen cruces rojas en apartados como Android toolchain o Chrome, por lo general se debe a licencias faltantes.

Solución: Abre tu terminal o consola y ejecuta el siguiente comando para aceptar de forma masiva todas las licencias del SDK de Android: 
flutter doctor --android-licenses

Presiona y (yes) a cada pantalla que aparezca en la consola.

2. Error: "Android toolchain - develop for Android devices... cmdline-tools component is missing"

Este error ocurre porque Android Studio no instala las herramientas de línea de comandos por defecto.

  1. Abre Android Studio.
  2. Ve a Tools > SDK Manager (o Settings > Languages & Frameworks > Android SDK).
  3. Haz clic en la pestaña SDK Tools.
  4. Busca y marca la casilla de Android SDK Command-line Tools (latest).
  5. Haz clic en Apply y espera a que termine la descarga.
